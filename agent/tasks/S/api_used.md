# 使った API（apidump で確認済み。Brigadier のみ apidump 対象外で標準 API）
- SavedData: net.minecraft.world.level.saveddata.SavedData(setDirty()) / SavedDataType(Identifier, Supplier<T>, Codec<T>, DataFixTypes) / DataFixTypes.LEVEL / MinecraftServer.getDataStorage() / SavedDataStorage.computeIfAbsent(SavedDataType<T>)
- 通信: PayloadTypeRegistry.serverboundPlay()/clientboundPlay().register(Type, StreamCodec) / ServerPlayNetworking.registerGlobalReceiver(Type, PlayPayloadHandler) / ServerPlayNetworking.send(ServerPlayer, CustomPacketPayload) / Context.player() / PlayerLookup.all(MinecraftServer)
- CustomPacketPayload(type()), CustomPacketPayload.Type(Identifier), StreamCodec.unit(V), StreamCodec.composite(6 引数版), StreamCodec.apply(CodecOperation), ByteBufCodecs.STRING_UTF8 / BOOL / list()
- イベント: ServerPlayConnectionEvents.JOIN(onPlayReady(ServerGamePacketListenerImpl, PacketSender, MinecraftServer)) / ServerGamePacketListenerImpl.getPlayer() / ServerLivingEntityEvents.AFTER_DEATH(afterDeath(LivingEntity, DamageSource)) / CommandRegistrationCallback.EVENT / CreativeModeTabEvents.modifyOutputEvent(ResourceKey) + FabricCreativeModeTabOutput.prepend(ItemLike)
- コマンド: Commands.literal/argument/hasPermission(PermissionCheck)/LEVEL_GAMEMASTERS(=権限2), CommandSourceStack.getServer()/sendSuccess(Supplier<Component>, boolean)。StringArgumentType.greedyString()/getString は Brigadier（dump 無し）
- アイテム: Item.Properties.setId(ResourceKey)/sword(ToolMaterial, float, float), ToolMaterial.WOOD, Registry.register(Registry, ResourceKey, T), BuiltInRegistries.ITEM(.containsKey(Identifier)/.getKey(T)), Registries.ITEM, Registries.CREATIVE_MODE_TAB, ResourceKey.create, ItemStack(ItemLike,int), Item.getDescriptionId(), Inventory.add(ItemStack), Player.drop(ItemStack, boolean), Player.getMainHandItem()
- モブ: EntityType.getKey(EntityType), EntityType.getDescriptionId(), EntityType.ENDER_DRAGON, DamageSource.getEntity()/getDirectEntity()
- 表示: ServerPlayer.sendSystemMessage(Component, boolean overlay), ServerPlayer.connection.send(Packet), ClientboundSetTitleTextPacket/SubtitleTextPacket(Component), ClientboundSetTitlesAnimationPacket(int,int,int), PlayerList.broadcastSystemMessage(Component, boolean), Component.literal/translatable/empty, MutableComponent.append/withStyle(ChatFormatting), MobEffectInstance(Holder,int,int), MobEffects.WITHER, LivingEntity.addEffect(MobEffectInstance)
- リソース形式: items/<id>.json(model type minecraft:model), models/item (parent item/handheld), data/<ns>/recipe/*.json（crafting_shapeless、files/ の vanilla で確認）
