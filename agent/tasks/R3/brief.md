# 指示書 R3: 読みがな辞書（パート3）
目的: マイクラ日本語名にしりとり用の読み（ひらがな）を付ける。
担当範囲: agent/readings/out3.json, agent/readings/unsure3.md だけ
入力: agent/readings/names3.json（名前の配列）
成果物: out3.json = {"名前": "よみ", ...}（入力の全名前ぶん、1つも欠かさない）
ルール:
- 読みは ひらがな と 「ー」だけ。カタカナはひらがなに直し、長音の「ー」は残す（ブレイズパウダー→ぶれいずぱうだー）
- 漢字はマイクラ日本語版で一般的な読み（垂れ根=たれね、原木=げんぼく、角笛=つのぶえ、金床=かなとこ、鍛冶台=かじだい、色付きガラス=いろつきがらす、羊毛=ようもう、苗木=なえぎ）
- 英字・数字は日本語の読み方で（TNT=てぃーえぬてぃー、TNT付きのトロッコ=てぃーえぬてぃーつきのとろっこ）
- 記号・空白・括弧は読みに入れない
- 読みが2通りありうる・自信がない名前は unsure3.md に「名前: 採用した読み / 別の候補」で書く
- 書き方: Python で辞書を組み立てて json.dump(ensure_ascii=False, indent=0)。最後に「入力の件数 = 出力の件数」「全読みが [ぁ-ゖー]+ に一致」を Python で確かめ、結果を返答に書く
返答: 「完了 / 件数と検査結果 / 不確かな件数」を3行以内
