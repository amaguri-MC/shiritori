# 不確かな読み（R1）
- ゾンビの頭 ほか「〜の頭」: あたま / ず
- スケルトンの頭蓋骨 ほか: ずがいこつ / とうがいこつ
- キノコの柄: え / がら
- ○○の木 / ○○の葉: き・は / ぼく・よう
- 〜の欠片(アメジスト・ネザライト・プリズマリン): かけら / けっぺん
- 〜の殻(オウムガイ・シュルカー): から / かく
- ファントムの皮膜: ひまく / かわまく
- ホタルの茂み: しげみ / もみ
- ドラゴンの火の玉: ひのたま / ひのだま
- アメジストの塊: かたまり / かい
- 〜の棚(木の棚): たな / だな
- ネザー金鉱石: きんこうせき / かなこうせき
- サルノコシカケ: さるのこしかけ（カタカナ表記をそのまま変換）
- 〜の花: はな / か
